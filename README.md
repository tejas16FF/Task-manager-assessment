# Task Manager App

## 🚀 Features

* Add tasks with priority (Low, Medium, High)
* Delete tasks
* Filter tasks by priority
* Task count display
* Form validation (min 3 characters)
* Data persistence using localStorage

## 🛠 Tech Stack

* React (Hooks)
* Zustand (State Management)
* Vite
* CSS

## 📦 Setup Instructions

git clone https://github.com/tejas16FF/task-manager-assessment.git
cd task-manager-assessment
cd task-manager
npm install
npm run dev

## 📌 Notes

* Used Zustand for global state
* Functional components only
* Responsive UI (mobile + desktop)
